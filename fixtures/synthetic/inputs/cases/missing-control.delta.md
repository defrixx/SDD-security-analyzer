# Публичные ссылки
Добавить новую операцию чтения приватного документа по публичной ссылке без сессии. Ссылку разрешено использовать доверенному получателю; надо сохранить конфиденциальность документа. Режим срока жизни, отзыва, проверки получателя и разграничения доступа пока не описан. Существующий API владельца не меняется. Удаления его контроля не предлагается.
