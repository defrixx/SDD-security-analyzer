# Продукт A — приватные документы
Маркер контекста: FIXTURE-PRODUCT-A-ALPHA.
Единственная бизнес-операция — чтение существующего документа. Публичных документов, создания, изменения и удаления нет.
API требует действительную сессию. Сервер отклоняет запрос при отказе проверки сессии.
Перед каждым чтением доменный сервис проверяет, что субъект — владелец документа; политика действует и для прямого API запроса. Gateway и интерфейс не заменяют проверку доменного сервиса.
Журнал содержит request_id и результат. Пароли, session IDs, access/refresh tokens, закрытые ключи, исходные Authorization headers, reset tokens, платёжные секреты и персональные данные в журнал не попадают.
В проекте нет MCP.
